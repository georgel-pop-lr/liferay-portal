# 407: Repeat the Call Instead of Looping Over a Literal Set

When the values a loop walks are a fixed set of constants or string literals written at the loop itself, do not loop over them. Write the statement out once per value, and when the repeated body is more than a line or two, extract it into a method and call that method once per value. Keep the loop when the collection comes from somewhere else: a parameter, a field, a service call, or values a call in the method computed.

**Rationale:** A loop over an inline `List.of(...)`, `Arrays.asList(...)`, or array literal presents the set as data when it is really three statements spelled sideways. It buys nothing at runtime, costs a level of indentation and a loop variable, and hides each value from a `git grep` for the constant next to the call it feeds, since the constant no longer sits on the same line as the operation it drives. Written out, the reader sees how many calls happen without counting the literal's entries, and each call is a statement that rule 202's ordering applies to in a form the reader can check.

Counted over `modules/apps`: 499 runs of three or more consecutive calls to the same method carrying a constant argument, spread over 326 production files, against 36 loops over an inline literal collection, of which 30 are tests. `_delete("BatchEngineExportTask")` three times in `DeleteStaleBatchEngineDataUpgradeProcess`, `_deletePortletPreferences("145")` three times in `PortletPreferencesUpgradeProcess`, and `_processXMLDependencies(analyzer, "WEB-INF/liferay-hook.xml", _XPATHS_HOOK)` three times in `WabProcessor` are the shape to write. No production loop over a fixed set of named constants has a body that is a single delegating call. The evidence is lopsided rather than unanimous: `ViewTreeManagementToolbarDisplayContext` loops over `new String[] {"all", "active", "inactive"}` and `KBArticleLocalServiceImpl` over `new String[] {"content", "title"}`, both with a multistatement body that uses the loop value several times.

A violation is a `for` loop whose collection is an inline literal of constants or string literals, where repeating the statement per value, or calling one extracted method per value, says the same thing.

**Example:** Brian Chan closed https://github.com/brianchandotcom/liferay-portal/pull/181612 over a `for (String roleName : List.of(DepotRolesConstants.DESIGN_LIBRARY_ADMINISTRATOR, DepotRolesConstants.DESIGN_LIBRARY_CONTENT_REVIEWER, DepotRolesConstants.DESIGN_LIBRARY_OWNER))` in `LayoutPageTemplateDepotRolePermissionsContributor` on LPD-104558 Grant the design library roles the add, update, and delete permissions on layout page templates (https://liferay.atlassian.net/browse/LPD-104558), giving both shapes in https://github.com/brianchandotcom/liferay-portal/pull/181612#issuecomment-5622803246: "do this 3 times or call a method 3 times that calls the add logic". The two contributors already shipping for the same roles, `FragmentDepotRolePermissionsContributor` and `StyleBookDepotRolePermissionsContributor`, each write their three role entries out one per role.
